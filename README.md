## 🛠️ Machine Work (Ye Website Kya Karti Hai?)
Ye simulator ek real CNC machine ki tarah kaam karta hai. Isme aap niche diye gaye kaam kar sakte hain:

1.  **3D Machine Visualization:** Pure CNC gantry aur spindle ka realistic 3D model (Three.js se bana hua).
2.  **NK105 G2 Virtual Remote:** Asli NK105 remote ki tarah buttons aur LCD display, jisse aap machine ko Jog (X, Y, Z move) kar sakte hain.
3.  **G-Code Processing:** Aap apna `.nc` ya `.gcode` file upload karke dekh sakte hain ki machine kaise chalegi.
4.  **Live Position Tracking:** X, Y, aur Z axis ki live coordinates (Machine aur Work coordinates).
5.  **Material & Tooling:** Material ki size (Width, Length, Thickness) set karna aur alag-alag tools (Endmill, Ballnose, V-Bit) mount karna.
6.  **Job Queue & Analytics:** Aane wale jobs ki list manage karna aur machine ki performance check karna.

## 🚀 Kaise Chalayein?
1.  **Jogging:** Remote ke yellow buttons (4, 6, 8, 2, 9, 3) se X, Y, Z axis ko move karein.
2.  **Set Zero:** `XY=0` aur `Z=0` buttons se apna work offset set karein.
3.  **Load Job:** 'LOAD G-CODE' button par click karke apni file select karein.
4.  **Start:** Green 'RUN' button dabakar simulation shuru karein.
